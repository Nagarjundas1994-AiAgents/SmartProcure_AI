# Security policy

Please report vulnerabilities **privately** through GitHub: *Security → Report a vulnerability*
(https://github.com/Nagarjundas1994-AiAgents/SmartProcure_AI/security/advisories/new). Do not open a public issue.

Never commit secrets (tokens, passwords, service keys, `default-env.json`, `.env`). Secret scanning and push protection are enabled;
if a secret is ever committed, **rotate it first**, then remove it from history.
